# Canimal Systems documentation

Static documentation for Canimal Systems Inc., built with Astro Starlight.

## Local checks

Use Node **24.21.0** (`.nvmrc`) and npm **11.19.0**. Then:

```sh
npm ci
ASTRO_TELEMETRY_DISABLED=1 npm run build
npm test
npx playwright install chromium
npm run test:browser
npm run preview
```

Preview binds only to 127.0.0.1. Search indexes are generated by the production build; use preview to check search. Do not expose the development/preview server publicly. Linux browser prerequisites may require `npx playwright install --with-deps chromium` on a disposable CI host.

Edit Markdown in `src/content/docs/`; explicit slugs preserve public URLs. Assets in `public/assets/` retain root URLs. Keep root `CNAME` and `public/CNAME` byte-identical. For intentional prose changes, review the source diff and update `review/content-baseline.json` hashes; never regenerate the baseline simply to bypass a failed preservation check.

See [framework decision, dependencies and rollback](review/ADR-001-framework.md) and [validation evidence](review/validation.md). Pull requests build/test and upload `docs-review` artifacts; they cannot deploy. Production needs a separate, authorized manual run on main with deploy enabled and the github-pages environment gate.

## CAN-USB cross-site regression (CSI-19)

`npm test` verifies the built datasheet's named product link and preserved docs
canonicals; `npm run test:browser` checks its keyboard activation. Website CI
independently checks real built HTTP redirects (including trailing slash/query
variants), product identity, canonical metadata, and unrelated 404s.

After a local build, run the read-only cross-site check:

```sh
# Before the companion website compatibility release: check the already-live target.
npm run test:links -- --canonical-only
# Full check against a locally running website build/Worker:
WEBSITE_ORIGIN=http://127.0.0.1:8787 npm run test:links
# After both separately authorized releases: check live docs AND website.
DOCS_ORIGIN=https://docs.canimal.io npm run test:links
```

The full check fails until the legacy redirects and product canonical metadata
are released. `--canonical-only` explicitly skips those checks; it is not full
acceptance. Live checks are intentionally separate from deterministic PR tests
so either repository can merge/release first without making CI depend on an
unreleased companion. See [release order and rollback](review/CSI-19.md).

# Canimal Systems documentation

Static documentation for Canimal Systems Inc., built with Astro Starlight.

## Local checks

Use Node **24.21.0** (`.nvmrc`) and npm **11.19.0**. Then:

```sh
npm ci
ASTRO_TELEMETRY_DISABLED=1 npm run build
npm test
npx playwright install chromium
npm run test:browser
npm run preview
```

Preview binds only to 127.0.0.1. Search indexes are generated by the production build; use preview to check search. Do not expose the development/preview server publicly. Linux browser prerequisites may require `npx playwright install --with-deps chromium` on a disposable CI host.

Edit Markdown in `src/content/docs/`; explicit slugs preserve public URLs. Assets in `public/assets/` retain root URLs. Keep root `CNAME` and `public/CNAME` byte-identical. For intentional prose changes, review the source diff and update `review/content-baseline.json` hashes; never regenerate the baseline simply to bypass a failed preservation check.

See [framework decision, dependencies and rollback](review/ADR-001-framework.md) and [validation evidence](review/validation.md). Pull requests build/test and upload `docs-review` artifacts; they cannot deploy. Production needs a separate, authorized manual run on main with deploy enabled and the github-pages environment gate.
